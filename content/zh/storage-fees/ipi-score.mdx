## 这个分数衡量的是什么

IPI 的评分区间是 **0到1000分**,大部分卖家的分数落在300到800之间。这个分数只对**Professional**计划、且有活跃 FBA 库存(近13周有活动记录)的卖家开放——新卖家或者只把 FBA 用于多渠道履约的卖家可能根本看不到自己的分数。

## 背后的四个评分因素

亚马逊的 Inventory Performance dashboard 从四个维度打分:

1. **超额库存占比**——供应量超过90天预测销量的库存会被判定为超额;亚马逊建议维持30-60天的库存覆盖水平。
2. **90天滚动动销率**——衡量库存相对于持有量的售卖速度,按滚动周期计算。
3. **搁浅库存占比**——账面上有库存,但因为 listing 问题导致卖不出去的部分。
4. **有货率**——你的热销品是否保持有货,按近30天和近60天的销量加权计算。

新建的 ASIN 有90天的宽限期,期间不计入分数。一旦你提交移除订单或清算请求,对应库存会立刻停止计入 IPI 分数——不过分数本身反映这个变化需要一定时间,因为它是按滚动周期计算的,不会瞬间归零。

## 分数区间和400分门槛

目前关键的门槛是**400分**。跌破这个门槛可能导致下个季度触发 FBA 仓储限制。已知的分数区间划分如下:

| 分数区间 | 状态 |
| --- | --- |
| 0-399 | 低于门槛——很可能触发仓储限制 |
| 400-499 | 合格,但没有缓冲空间 |
| 500-649 | 健康 |
| 650-799 | 优秀——最大仓储容量 |
| 800-1000 | 顶尖(少数卖家能达到) |

另外要注意区分:亚马逊的 FBA New Selection 项目有自己独立的准入门槛——需要**300分或以上**才能参加这个项目。这和触发一般仓储限制的400分门槛是两码事,阅读 IPI 相关要求时不要把这两个数字搞混。

亚马逊在每个季度末评估 IPI 分数,并据此设定你下个季度的仓储容量上限(以立方英尺计)。因为Q4是销售旺季,进入旺季前分数偏低的代价会格外大。

## 为什么临时抱佛脚提升不了分数

亚马逊的动销率等各项指标是按滚动周期(大致是过去90天)计算的,所以评估前的短期突击操作效果有限。举个动销率的计算例子:如果你四周内的平均可用库存是 (50+40+150+80)/4 = 80件,同期卖出了120件,那动销率就是 120/80 = 1.5。

提交移除订单本身**不会**提升你的 IPI 分数——它只能阻止分数继续下滑,因为对应库存从此不再拖累后续的计算。

## 怎么提升这个分数

- **处理搁浅库存**,重新上架该商品,或对相关库存提交移除订单。
- **减少超额库存**,主动清理占比过高的滞销库存。
- **提升动销率**,通过广告投放和优化 listing 来加快出货速度。
- **保护有货率**,避免主力单品断货——哪怕其他方面都做得不错,热销品断货也会拖累这项指标。
