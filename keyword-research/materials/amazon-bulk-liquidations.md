# amazon bulk liquidations

## Amazon Bulk Liquidations Store（Beta Program）— 官方帮助页（核心信源，该关键词与页面标题完全对应）
- 链接: https://www.amazon.com/gp/help/customer/display.html?nodeId=T0SulrJwRKDdSNHxi3
- 要点:
  - "Bulk Liquidations Store" 是 Amazon 官方直营的清算购买页面，卖 palletized lots（打托批次），来源是 Amazon 自营库存或第三方卖家库存，分两类：**overstock（全新未拆封）** 或 **damaged（客退/处理中损坏）**，每个 lot 是一批固定商品的单一 listing。
  - **目前是 Beta 阶段**，只对入驻的 beta 客户开放，入驻条件：① Amazon Business 账号；② 加入 Amazon Tax Exemption Program (ATEP)；③ 同意条款。地域限制：仅美国本土（contiguous US）。未入驻账号无法加购物车，需先加入 waitlist。
  - **定价机制与拍卖制平台不同**：Bulk Liquidations Store 是**固定价格，不可议价，不是拍卖**（这点和 B-Stock 等拍卖平台形成对比，写文章时可以专门拎出来对比）。
  - 售后：不支持退换货，只有"数量对不上"或"货物损坏到无法使用"能在收货 7 天内申请退款，联系邮箱 bulk-liquidations-beta@amazon.com。
  - 大件订单可能需要叉车/月台卸货，Amazon 不保证具体到货时间窗口。

## amzprep.com — Amazon Liquidation Pallets 指南（对"bulk"这个词对应的品类划分很清晰）
- 链接: https://amzprep.com/amazon-return-pallets
- 要点:
  - 把清算批次明确分成三类，"bulk"通常对应第三类：
    1. **Customer Return Pallets**（最常见）：买家买了又退的商品，成色从"像新的"到"损坏"都有，需要仔细验货。
    2. **Amazon Warehouse Pallets（Overstock）**：全新未拆封、从未卖出去的库存，因季节性清仓/停产/超额库存被下架，风险最低、转售价值最高，**可售率 80–95%**，转售价约为零售价的 60–80%，单托价格 **$400–$1,200**。
    3. **Amazon Bulk Pallets（Mixed Lots，即"bulk liquidations"对应的形态）**：把客退、overstock、shelf-pull 混在一起打包的大批量货，**单托件数 300–500+ 件**。
  - Customer Return Pallets 可售率仅 **20–60%**（取决于 manifest 准确度和成色分级），单托价格 **$200–$900**。
  - "Amazon Mystery Pallet"（不带清单的盲盒批次）：**60–70% 的商品可能不可售或需要维修**，因为清算商为了省人工，跳过了分拣/扫描/分级这一步，所以价格会更低但风险更高。
  - 也提到 Amazon 官方的 Bulk Liquidations Store（同上，需要 ATEP + 固定价 + 仅限美国本土 + 一口价不可议价）。

## B-Stock 官方博客 — "Where & How to Buy Amazon Return Pallets"
- 链接: https://bstock.com/blog/where-how-to-buy-amazon-return-pallets
- 要点:
  - 给出行业级退货率数据：**2023 年电商退货率 17.6%，2026 年预计升至 19%**——这是驱动"清算/bulk liquidations"这门生意存在的根本原因（退货量太大，零售商必须批量甩货）。
  - 强调很多客退商品其实是**买家反悔/不需要了/和预期不符**导致的退货，本身是全新未拆封的，不代表"bulk liquidations"里的货都是坏的。
  - 买家操作路径：先注册企业账号+拿到 resale certificate，再去 Amazon Liquidation Auctions（走 B-Stock）浏览批次，下单前必须核对：manifest、商品成色、预估零售价、运费、批次大小、卖家条款。
  - 不同零售商店铺（storefront）的条款不同，但 Amazon Liquidation Auctions 遵循和大多数 B-Stock 店铺一致的统一成色/包装标准。

## Direct Liquidation 官方博客 —"卖家视角"的关键背景信息（对内容站主受众——FBA 卖家——非常关键）
- 链接: https://www.directliquidation.com/blog/post/buy-amazon-customer-returns-pallets-online
- 要点（**这段是从"Amazon 怎么处理不可售库存"的角度写的，直接对应本站真正目标读者：FBA 卖家，而不只是清算货买家**）：
  - Amazon 目前给卖家提供 **4 种处理不可售库存的方式（都会收费）**：**Return to Seller（退回卖家自行处理）、Disposal（销毁）、Liquidation（清算）、FBA Grade and Resell（分级转售，目前仅邀请制开放）**。
  - **卖家如果选择走清算（Liquidation），大约能拿回售价的 5%–20%**——这是一个具体的、可以直接用在"值不值得清算"这类内页里的关键数字。
  - Amazon 自己也承认此前因为"直接销毁退货商品"被媒体批评（third-party 卖家告诉 CNBC 他们大约会扔掉三分之一的退货商品），因此才推出"零销毁目标（zero product disposal）"相关的清算/转售项目作为替代方案。
  - 走 FBA 的商品，Amazon 会把退货分类为：sellable / damaged / customer-damaged / defective / carrier-damaged / expired；如果损坏是 Amazon 或物流商造成的，商品所有权转移给 Amazon 且会赔付卖家，这类商品之后会被 Amazon 整卡车批量出售。
  - 电子产品退货会走单独流程：检测+维修后上架 **Amazon Renewed**（翻新品渠道），但第三方卖家想把自己的商品送进 Amazon Renewed 门槛很高、规则严格。

## Amazon 官方帮助中心补充

文件顶部已有的 `Amazon Bulk Liquidations Store（Beta Program）` 官方帮助页（`https://www.amazon.com/gp/help/customer/display.html?nodeId=T0SulrJwRKDdSNHxi3`）是 **amazon.com 客户帮助域名**下的页面，不是 sellercentral.amazon.com 卖家侧域名。本轮专门用 `site:sellercentral.amazon.com` 搜过有没有卖家侧对应的说明页，搜到的唯一同名相关结果是 **"Amazon Bulk Services: Referral fee discount"**（`https://sellercentral.amazon.com/help/hub/reference/external/GZUL88U2RJ3LJ9JK`）——**核实后确认这是完全不同的项目**：Amazon Bulk Services 是"帮卖家以整箱/整托方式向买家批量销售自己商品、换取推荐费折扣"的项目，跟"卖家把滞销库存清算给清算商"这个"bulk liquidations"的语境毫无关系，为避免误导没有采纳，也提醒后续写文案时注意别把这两个同样带"bulk"字样的项目搞混。

没有找到 sellercentral.amazon.com 域名下专门对应"卖家把库存批量清算掉"这件事的独立页面（该主题的官方说明主要落在已经用于其他关键词素材文件的 "FBA Liquidations" / "Value-recovery services" 页面里）。这两个页面的完整正文后来改用 `mcp__jina__read_url` 成功抓到（此前用 WebFetch 被登录墙挡住），已分别记录在 `amazon-liquidation-program.md`（FBA Liquidations 页）和 `amazon-liquidation-pallets.md`（Value-recovery services 页，含 FBA Liquidations/Amazon Outlet/Refurbishment/FBA Grade and Resell/FBA Donations 五条并行回收路径的完整说明），此处不重复展开，直接互相引用即可。
